Accessibility

Accessibility is a product requirement.

Regulated Infinity Labs aims to make this website and its software understandable and operable without relying on a particular input method or visual presentation.

Website approach

  • Semantic HTML and meaningful heading structure.
  • A skip link for direct access to main content.
  • Keyboard-visible focus indicators and no mouse-only interaction.
  • Responsive layout with readable text at narrow widths and zoom.
  • No client-side JavaScript required for navigation or content.
  • Reduced-motion preferences are respected.
  • Meaningful alternative text is provided for informational imagery.

Conformance target

The website is designed toward WCAG 2.2 Level AA. It has not yet undergone an independent formal accessibility audit, so this statement does not claim certified conformance.

PulseRail

PulseRail is being developed with screen-reader operation, explicit state communication, clear next actions and non-visual interaction as first-order requirements. Accessibility findings are treated as product defects.

Feedback

A permanent public accessibility-contact channel will be published before general distribution of PulseRail. Until then, this page records the current accessibility commitment and known audit status.

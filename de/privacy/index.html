Website-Datenschutz

Kleine Website, bewusst kleiner Datenfußabdruck.

regulatedinfinity.com verwendet keine Werbung, Marketing-Analytics, Nutzerkonten oder Social-Media-Tracker.

Cloudflare

Die Website wird über Cloudflare Workers und Static Assets ausgeliefert. Für die erste Sprachwahl kann grobe Länderinformation der Anfrage verwendet werden. Die manuelle Auswahl hat immer Vorrang.

Spracheinstellung

Eine manuelle Auswahl speichert bis zu ein Jahr das First-Party-Cookie site_lang. Es dient nur dazu, die gewählte Sprache beizubehalten.

Hell/Dunkel

Die Darstellung wird lokal im Browser unter ril-theme gespeichert. Vor einer manuellen Wahl folgt die Seite der Systempräferenz.

Vor Veröffentlichung

Die Seite ist während der Entwicklung mit noindex markiert. Das reduziert die Auffindbarkeit in Suchmaschinen, ist aber keine Zugriffssperre.

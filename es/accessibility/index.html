Accesibilidad

La accesibilidad es un requisito del producto.

El sitio usa HTML semántico, foco visible con teclado, diseño adaptable, modos claro y oscuro y texto alternativo para imágenes informativas.

El objetivo es WCAG 2.2 nivel AA; todavía no se afirma una conformidad auditada de forma independiente.

PulseRail se desarrolla con lector de pantalla, anuncios de estado, orden de foco y comunicación no visual como requisitos funcionales.

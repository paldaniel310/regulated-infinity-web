Privacidad del sitio

Un sitio pequeño con una huella de datos deliberadamente pequeña.

regulatedinfinity.com no usa publicidad, analítica de marketing, cuentas de usuario ni rastreadores sociales.

Cloudflare

El sitio se sirve mediante Cloudflare Workers y Static Assets. Puede utilizar información aproximada de país para sugerir inicialmente uno de los ocho idiomas disponibles. La selección manual siempre prevalece.

Preferencia de idioma

La selección manual guarda durante un máximo de un año la cookie propia site_lang, únicamente para recordar el idioma.

Preferencias de presentación

El modo claro u oscuro se guarda localmente como ril-theme. La vista de lectura se guarda solo en el navegador como ril-reading y cambia alineación, interlineado, ancho de lectura y ciertos diseños. El código propio del sitio no envía estas preferencias al servidor ni las usa para perfiles, publicidad o analítica.

Antes de publicación

El sitio usa noindex durante el desarrollo. Esto reduce su visibilidad en buscadores, pero no es control de acceso.

La aplicación tiene su propia información de privacidad.

PulseRail · 1.0.0-rc4

D’un projet Android complet à un build traçable — depuis le téléphone.

PulseRail importe un ZIP complet, inspecte le projet, coordonne un build privé GitHub Actions, vérifie l’artefact exact et préserve l’identité de signature. Le but n’est pas un bouton Build de plus, mais un chemin capable d’expliquer son résultat.

Release candidate · tests propriétaire

Construire depuis le téléphone. Garder les preuves.

Dépôt, commit, run, attempt, artefact, paquet, version, hash et signataire font partie de l’état du produit.

Documentation PulseRail

Un build réussi peut encore laisser des questions dangereuses.

Quelle source a produit cet APK ?

L’artefact est relié au dépôt, au commit exact, au run et à l’attempt.

Quelle application peut-il mettre à jour ?

Identité de paquet et lignée de signature forment l’identité de mise à jour.

La récupération a-t-elle dupliqué le travail ?

Le travail distant existant est réconcilié avant toute opération de remplacement.

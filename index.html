Current work

PulseRail

PulseRail is a phone-side Android application for importing complete Android project ZIPs, coordinating controlled cloud builds, verifying exact artifacts and supporting explicit phone or Wear OS delivery flows.

1.0.0-rc4 · owner testing

Build from the phone. Keep the evidence.

PulseRail treats source identity, build provenance, signing lineage and artifact verification as part of the product workflow rather than hidden implementation detail.

Engineering principles

Reliability is a product feature.

Regulated Infinity Labs focuses on software where the system should be able to explain what happened, what evidence supports it and what the user needs to do next.

Verifiable by design

Important outcomes are bound to explicit identities, hashes, versions and state rather than inferred from appearance alone.

Fail closed

Uncertain evidence does not silently become authority for destructive repair, signing, installation or other high-impact actions.

Accessible interaction

Keyboard and screen-reader operation, clear next actions and non-visual state communication are treated as first-order interface requirements.

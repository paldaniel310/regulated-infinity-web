Website privacy

A small site with a deliberately small data footprint.

regulatedinfinity.com is designed as an informational site without advertising, analytics, user accounts, contact forms or third-party marketing scripts.

Cloudflare delivery

The website is served through Cloudflare Workers and Static Assets. Normal web requests therefore pass through Cloudflare’s delivery and security infrastructure. Cloudflare makes coarse request-location metadata such as a country code available to the Worker.

Initial language suggestion

On an unlocalized English URL, the site may use Cloudflare’s coarse country code to choose an initial language from the eight supported localizations. Hungary maps to Hungarian; countries with a clear supported language may map to that language; ambiguous multilingual cases may also consider the browser’s language header. If the site cannot make a reasonable supported choice, it stays in English.

The website code does not need the visitor’s raw IP address for this decision and does not create its own IP-address log. The country-based choice is only an initial suggestion and can always be overridden with the language selector.

Language preference cookie

When a visitor chooses a language manually, the site stores a first-party site_lang cookie for up to one year. Its only purpose is to remember that explicit language choice so country inference does not override it on later visits. It does not contain an account identifier and is not used for advertising or analytics.

Appearance and reading preferences

The two-state appearance control stores the selected light or dark theme in browser local storage under ril-theme. Before a manual choice is made, the page follows the operating system’s preferred color scheme.

The optional reader-friendly control stores only the presentation choice under ril-reading. That value changes text alignment, line spacing, reading width and selected layout behavior in the browser. Neither preference is sent to the server by the site’s own code, and neither is used for profiling, advertising or analytics.

No marketing analytics

The current website contains no advertising pixels, behavioral analytics libraries, social-media trackers or third-party embedded content. If that changes in a way that materially changes visitor data handling, this notice will be updated before the feature is treated as production behavior.

PulseRail is separate

This notice covers the website. The application has different workflows and external-service integrations; its current pre-release design is described on the PulseRail privacy page.

Pre-publication status

The site is intentionally marked noindex while PulseRail remains pre-release. This reduces search-engine discovery but is not access control: anyone who knows the address can still open the site.

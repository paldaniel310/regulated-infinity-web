PulseRail · 1.0.0-rc4

De um projeto Android completo a um build rastreável — pelo celular.

O PulseRail importa um ZIP completo, inspeciona o projeto, coordena um build privado no GitHub Actions, verifica o artefato exato, preserva a identidade de assinatura e oferece entrega explícita para telefone ou Wear OS.

Release candidate · testes do proprietário

Compile pelo celular. Preserve as evidências.

Repositório, commit, run, attempt, artefato, pacote, versão, hash e assinante fazem parte do estado do produto.

Documentação do PulseRail

Um build bem-sucedido ainda pode deixar perguntas perigosas.

Qual fonte gerou este APK?

O artefato é vinculado ao repositório, commit exato, run e attempt.

Qual app ele pode atualizar?

Package ID e linhagem de assinatura formam a identidade de atualização.

A recuperação duplicou trabalho?

O trabalho remoto existente é reconciliado antes de criar uma substituição.

Evidência antes de autoridade.

Verificável por projeto

Identidades, hashes, versões e estado explícito ligam o resultado à origem.

Fail closed

Evidência incerta não vira permissão automática para ações de alto impacto.

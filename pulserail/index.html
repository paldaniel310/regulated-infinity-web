PulseRail

Android project builds with explicit provenance.

PulseRail is a phone-side Android application for complete Android project ZIPs. It coordinates project intake, GitHub Actions builds, artifact verification and controlled export or installation flows.

Status: PulseRail 1.0.0-rc4 is under active release-candidate development.

Core workflow

  • Import one complete Android project.
  • Inspect build requirements and project health.
  • Run the project build through a private GitHub workspace.
  • Verify the resulting artifact against its source and build identity.
  • Export or install supported verified artifacts.

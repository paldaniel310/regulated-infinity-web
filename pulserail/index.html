Pre-publication preview · PulseRail

Build from the phone. Keep the evidence.

PulseRail is a phone-side Android application for complete Android project ZIPs. It coordinates project intake, controlled GitHub Actions builds, artifact verification and explicit phone or Wear OS delivery flows.

Status: PulseRail 1.0.0-rc4 is in active release-candidate development and owner testing. It is not yet generally available.

Core workflow

One project, one traceable build path.

PulseRail is designed to preserve source, build and artifact identity through the full workflow rather than treating a successful build as sufficient proof on its own.

Import

Accept one complete Android project ZIP and validate its structure before it becomes the active project.

Inspect

Evaluate project health and actual build requirements, with deterministic repair kept separate from uncertain guidance.

Build

Coordinate the canonical GitHub Actions build through a private workspace with persisted transaction state.

Verify

Bind the resulting artifact to its repository, source revision, workflow run, package identity, version, hash and signer.

Deliver

Export a verified phone APK for explicit Android installation or use the bounded Wear OS installation flow for supported watch artifacts.

Recover

Resume or reconcile interrupted work after network loss or process death instead of silently creating a duplicate build.

Build Doctor

Repair authority follows evidence.

Build Doctor distinguishes project-health findings, requirements, deterministic safe repair and guided intervention. Uncertain evidence remains diagnostic rather than becoming automatic authority to change the project.

Bounded repair

Safe repairs are designed around explicit approval, exact changes, reinspection and rollback when expected invariants no longer hold.

Protected identity

Application identity, signing lineage and other protected project boundaries are preserved rather than silently replaced for convenience.

Delivery

Verified source and verified target.

Phone

A verified APK is exported to Android Downloads. The user starts the operating system's normal installation flow explicitly.

Wear OS

The watch flow checks artifact identity, the selected authenticated watch and installation readiness before one scoped installation operation.

Recovery

Optional signing recovery is account-first and designed to preserve the existing application's update lineage instead of silently replacing it.

Availability

Release candidate, not a public release.

PulseRail 1.0.0-rc4 remains under active integration and acceptance work. Public availability, final support channels, production service disclosures and release terms will be published before broader distribution.

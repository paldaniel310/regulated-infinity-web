PulseRail · support

Support and diagnostics

Release-candidate status: PulseRail 1.0.0-rc4 is currently under owner testing and is not yet generally available. A permanent public support channel will be published before broader distribution.

Before reporting a problem

  1. Confirm the exact PulseRail version shown in the application.
  2. Note the screen or workflow stage where the problem occurred.
  3. If a build was involved, keep the build or run identity shown by PulseRail.
  4. Use the application's status refresh or recovery path when one is offered.
  5. Remove confidential credentials and unrelated personal information from any diagnostic material.

Useful diagnostic information

A useful report normally includes the app version, Android version, device model, the visible PulseRail state or error category, approximate time of occurrence and the relevant build or run identity when available.

Build and recovery problems

PulseRail is designed to preserve build transaction identity across network loss and process death. When an operation appears interrupted, prefer the product's recovery or refresh action over starting replacement work manually.

Signing problems

If PulseRail reports that the required signer is missing or incompatible, treat that as an application-identity problem rather than a generic build failure. The intended recovery path is to restore the correct update identity, not silently substitute another one.

Wear OS installation problems

The watch installation flow checks the selected watch and the verified artifact before installation. If either changes, return to the readiness flow and let PulseRail re-check the operation.

Accessibility issues

Accessibility defects are product defects. A useful report identifies the assistive technology in use, the affected screen or control, what was announced or exposed, and what the user expected to happen. See the site's Accessibility page.

Public support channel

The production support address and reporting process will be published here before PulseRail is offered for general public distribution.

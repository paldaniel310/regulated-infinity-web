PulseRail · release status

Previewed, not published.

PulseRail 1.0.0-rc4 is an active release candidate under owner testing. The website documents the product direction and current implementation, but it does not constitute a public software release or an offer of a production service.

No public download yet

No generally available PulseRail package is distributed from this site at this stage. A future public release will identify the exact version, distribution channel, integrity information and applicable release documentation.

Release-candidate claims

Descriptions on this site distinguish intended product behavior, implemented RC4 behavior and work that still blocks final acceptance. In particular, completion of the browser-based GitHub App onboarding cutover and final whole-product acceptance remain pre-release work.

No functional certification from a build result

A successful compilation or CI run is evidence that specific checks passed. It is not represented as proof that every user workflow, device configuration or external integration has been functionally certified.

Final terms will follow the distribution model

Final licensing, distribution terms, warranty and support language will be published before broader availability, once the actual release and service model is fixed. This pre-release page does not invent terms for a distribution model that has not yet been finalized.

PulseRail · 1.0.0-rc4

От полного Android-проекта к прослеживаемой сборке — прямо с телефона.

PulseRail импортирует полный ZIP проекта, проверяет его состояние, координирует приватную сборку GitHub Actions, верифицирует точный артефакт, сохраняет идентичность подписи и поддерживает явную доставку на телефон или Wear OS. Это не просто ещё одна кнопка Build, а путь сборки, который может объяснить сам себя.

Release candidate · тестирование владельцем

Собирайте с телефона. Сохраняйте доказательства.

Репозиторий, commit, workflow run, attempt, артефакт, пакет, версия, хэш и подписант являются частью состояния продукта.

Полная документация PulseRail

Зачем это нужно

Успешная сборка всё ещё может оставлять опасные вопросы.

Какой исходник создал этот APK?

Артефакт связывается с репозиторием, точным commit, run и attempt, а не только с именем файла.

Какое приложение он может обновить?

Идентификатор пакета и цепочка подписи — это идентичность обновления. Несовпадение блокирует операцию.

Recovery не создал дубликат?

После сбоя сети или процесса сначала сверяется уже существующая удалённая работа.

Разрешена ли именно эта правка?

Safe Build Repair привязывает согласие к точному источнику, предложению, требованиям и набору изменений.

Что происходит с подписью?

Отсутствующая идентичность подписанта не заменяется молча новой только ради установки.

Можно ли работать невизуально?

Скринридер, фокус, озвучивание состояния и ясное следующее действие считаются функциональностью продукта.

Инженерные принципы

Сначала доказательство, потом полномочие.

Проверяемость по замыслу

Ключевые результаты связаны с явными идентификаторами, хэшами, версиями и состоянием.

Fail closed

Неопределённые данные не превращаются автоматически в разрешение на опасное действие.

Recovery — нормальный путь

Мобильные процессы завершаются, сеть пропадает; транзакционная модель должна это учитывать.

Узкие границы доверия

Источник, сборка, верификация и подписание разделяются там, где это возможно.

Доступность = корректность

Состояние, которое существует только визуально, сообщено неполно.

Заявления следуют доказательствам

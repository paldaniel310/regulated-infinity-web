PulseRail · оркестрация Android-сборки

У Android-сборки должна быть проверяемая цепочка происхождения.

PulseRail проводит полный Android-проект от импорта через контролируемую облачную сборку и точную проверку артефакта к сохранению идентичности подписи и явной доставке на телефон или Wear OS.

Отличие: «workflow succeeded» не является финальным ответом. PulseRail также связывает источник, run, attempt, артефакт, пакет, версию и подписанта.

Полный процесс

Один проект. Одна объяснимая транзакция.

Импорт

Принять полный ZIP проекта и проверить структуру до активации.

Инспекция

Определить реальный Gradle root, состояние проекта и релевантные требования.

Ремонт при достаточных доказательствах

Safe Build Repair связан с точным источником, предложением, требованиями, изменениями и согласием.

Сборка

Координировать канонический GitHub Actions workflow в приватном workspace с сохранённым состоянием транзакции.

Recovery

Сверять существующую удалённую работу после сбоя сети или процесса до запуска замены.

Верификация

Связать repository, commit SHA, run ID, attempt, artifact ID, package, version, APK hash и signer.

Build Doctor

Диагноз — не разрешение.

Build Doctor разделяет находки, требования, детерминированный безопасный repair и неопределённые рекомендации.

Требования имеют смысл

Minimum, maximum, exact, range, supported set, checksum и advisory не интерпретируются одинаково.

Доказательства должны быть свежими

Устаревший или противоречивый источник может помочь диагностике, но не дать право на автоматический repair.

Оригинал сохраняется

Safe Repair создаёт copy-on-write ревизии и заново проверяет результат.

Идентичность защищена

Application ID и signing lineage не переписываются молча.

GitHub connection

Цель RC4 — браузерный поток PulseRail GitHub App. Текущий Setup Wizard всё ещё содержит исторический fine-grained PAT-first путь; завершение перехода остаётся RC4 blocker.

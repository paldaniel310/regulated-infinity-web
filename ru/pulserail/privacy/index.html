Черновик: PulseRail 1.0.0-rc4 всё ещё находится в разработке и тестировании.

Продукт обрабатывает выбранный Android-проект, идентичности source/build/artifact, ограниченное recovery-состояние и, при использовании Wear OS, необходимые сведения о выбранных часах.

GitHub используется как build-платформа. Цель RC4 — браузерный GitHub App onboarding; интеграция ещё не завершена. Опциональное восстановление подписи привязано к явно выбранному Google-аккаунту.

Финальная информация об ответственном лице, провайдерах, сроках хранения и правах будет опубликована до общего релиза.

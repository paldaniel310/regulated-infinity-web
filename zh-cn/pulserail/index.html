PulseRail

Android 构建也应该拥有可验证的来源链。

PulseRail 将完整项目从导入和检查带到 GitHub Actions 构建、精确产物验证、签名身份保留以及手机或 Wear OS 交付。

“workflow succeeded”不是最终答案。源、run、attempt、artifact、package、version 和 signer 也必须彼此一致。

一个项目。一条可解释的事务路径。

导入与检查

验证项目 ZIP、真实 Gradle root、项目健康状态和相关要求。

受控修复

Safe Build Repair 绑定精确源、提案、要求证据、变更集和批准。

构建与恢复

保存事务身份，中断后先核对已有远程工作。

验证

绑定 repository、commit、run、attempt、artifact、package、version、hash 和 signer。

手机

验证后的 APK 交给用户明确启动 Android 正常安装流程。

Wear OS

安装前重新检查产物和所选已认证手表。

诊断不等于授权。

Build Doctor 将确定性安全修复与不确定指导分开。过期或冲突证据可以帮助诊断，但不能自动授权修改项目。
